Summary

Goal
Request a two-pulse haptic with every rendered heart beat.
Source
Use the browser Vibration API and the existing heartBeat animation.
Surface
animationstart and animationiteration on .heart in index.html.
Schema
None.
Mobile
Uses device haptics only where navigator.vibrate is available and permitted.
Open Qs
0.

Algorithm

  1. Listen for heartBeat starts and iterations on .heart.
  2. Delay 60_000 / 72 × 0.1 = 83.33ms to align the first haptic with the first visual contraction.
  3. Request navigator.vibrate([14, 136, 18]) to match the second contraction at 28% of the cycle.
  4. Skip a request when the document is unfocused, hidden, reduced-motion, unsupported, or rejected.
