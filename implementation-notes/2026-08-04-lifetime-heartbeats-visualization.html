Algorithm

  1. Read bpm and years from native range inputs.
  2. Compute beats = bpm * 60 * 24 * 365.2425 * years.
  3. Render the result as rounded billions and map it to a finite bead grid where each bead equals 50,000,000 beats.

UI layout

  1. Header: state the approximate answer first and put the formula close to it.
  2. Diagram: use a bead field, annotation ticks, and a pulse trace to show scale without dashboard chrome.
  3. Controls: expose only average BPM and lifespan because both visibly change the estimate.
  4. Notes: cite heart-rate range and life-expectancy anchor near the assumptions they support.
