Summary

Goal
Use editable age and country-level life expectancy in the live heartbeat estimate.
Source
World Bank indicator SP.DYN.LE00.IN, latest non-null country value.
Surface
index.html model-settings popover and live counts.
Privacy
Read a country from the browser locale only after an explicit button press; request no GPS location.
Fallback
Retain United States · 79.0 years when remote data is unavailable.
Mobile
Keep the settings panel inside the existing fixed mobile popover.
Open Qs
0.

Algorithm

  1. Resolve a country from manual input or the browser-locale region.
  2. Fetch /v2/country/all/indicator/SP.DYN.LE00.IN?format=json&mrnev=1&per_page=400 once.
  3. Set lifeYears = countryValue; calculate remaining = max(0, (lifeYears − age) × beatsPerYear − elapsedSeconds × bpm / 60).
  4. Retain lifeYears = 79 if country data is unavailable.

UI layout

  1. Top bar: retain the research link and replace the exposed age field with a Model trigger.
  2. Settings panel: group age, country, browser-locale action, data status, and scope note.

Decisions

IDChoice · Rationale
D-001Use country-level selection and browser locale. Avoid collecting precise coordinates.
D-002Use World Bank’s latest non-null life-expectancy observation. Keep estimates current without bundling a country table.
D-003Fetch every country observation once. Avoid per-country edge-service failures during location changes.

Tradeoffs

IDPicked over Rejected · Reason
T-001Browser locale over GPS geolocation. Preserve privacy and avoid a third-party reverse-geocoding service.
T-002Country-level life expectancy over a personal forecast. The source supports population estimates only.
T-003One cached all-country request over requests per country. Keep country changes immediate and resilient.

Assumptions

  • A-001 · Treat country life expectancy at birth as an illustrative model input; if wrong, replace it with a user-entered lifespan.
  • A-002 · Treat browser locale as a country suggestion; if absent or wrong, use the manual field.

Reversibility

R-001 · low. Remove the settings panel, network helpers, and dynamic lifespan state to restore the fixed 79-year model.

Definition of done

  • Changing age or country updates the live counter, fired count, total, and remaining percentage.
  • Browser-locale selection changes the model without requesting GPS permission.
  • Remote-data failure preserves a usable default estimate.
  • Desktop and 320px mobile checks show no overflow or console errors.
