Algorithm

  1. Compute beatsPerYear = 72 * 60 * 24 * 365.2425.
  2. Compute baseRemaining = max(0, (79 - age) * beatsPerYear).
  3. Subtract elapsedSeconds * 72 / 60 from remaining beats on a timer.
  4. Set the vertical bar height to remaining / total.

UI layout

  1. Top nav: left title, right About link and age input.
  2. Counter: large remaining-beats number above the heart.
  3. Heart: single inline SVG heart image pulsing at 72 bpm.
  4. Bar: vertical bar showing remaining beats, with fired beats above.
