Summary

Goal
Advance both live totals at the primary visible heart contraction.
Source
Use the existing heartBeat animation event and its 10% primary peak.
Clock
Use each rendered animation cycle as the model heartbeat clock.
Reset
Restart the CSS animation when age or country changes to reset every phase together.
Arithmetic
Store modeled totals and displayed balance as whole heartbeat counts.
Haptics
Invoke the existing vibration request in the same scheduled beat callback.
Reduced motion
Keep the discrete counter cadence without triggering motion or haptics.

0.

Algorithm

  1. Reset beatsSinceReset = 0; render the integer baseline; restart .heart animation.
  2. Receive animationstart or animationiteration; wait BEAT_DURATION_MS × 0.1 for the primary peak.
  3. Increment beatsSinceReset; render remaining = max(0, baseRemaining - beatsSinceReset); request haptics.
  4. Schedule the same integer step every BEAT_DURATION_MS when prefers-reduced-motion disables the animation.
  5. Discard a pending callback whose modelRevision predates an age or country reset.

Decisions

IDChoice · Rationale
D-001Use the rendered heartBeat timeline as the counter clock. It makes the live values, primary contraction, and haptic request share one beat boundary.
D-002Restart .heart on model resets. Age and country changes begin the counter and visual cycle at the same phase.
D-003Run the same discrete cadence without motion when prefers-reduced-motion is enabled. Preserve a live model without creating a visual or haptic beat.

Tradeoffs

IDPicked over Rejected · Reason
T-001Integer updates on rendered beats over continuous elapsed-time sampling. A visible heartbeat now always causes one matching counter step.

Assumptions

  • A-001 · “Perfectly synced” means the displayed heartbeat, fired total, remaining total, and best-effort haptic change at the same visible primary pulse.

Reversibility

R-001 · low. Restore elapsed-time rendering, omit animation restarts, and reinstate the periodic render timer.

Definition of done

  • Every primary visual contraction increments firedCount by one and decrements remainingCount by one.
  • Changing age or country restarts the visual pulse and counter model together.
  • Reduced motion retains the discrete counter cadence without invoking the heart animation or haptic request.
  • Browser checks record counter steps at ~95ms into the 833ms cycle, within one rendered frame of the ~83ms primary peak, with no console errors.
