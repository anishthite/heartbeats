Algorithm

  1. Compute total = bpm * 60 * 24 * 365.2425 * lifespan.
  2. Compute fired = min(age, lifespan) * beatsPerYear + elapsedSeconds * bpm / 60.
  3. Render odometer digits from remaining = max(0, total - fired).
  4. Render cycle rating with percentFired = fired / total.

UI layout

  1. Odometer: rolling remaining-beat digits and one pulse dot.
  2. Cycle rating: part-rating style ring with fired, remaining, and lifetime contractions.
  3. Controls: keep native sliders for age, lifespan, and pulse.
